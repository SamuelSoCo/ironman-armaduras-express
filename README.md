# Proyecto Web: Las Mejores Armaduras de Iron Man

Aplicación web desarrollada con **Node.js** y **Express** para la materia Web 2. Muestra un menú dinámico desplegable para navegar entre páginas HTML con información y fotos de las armaduras de Iron Man, así como un consumo de endpoint API local.

## 🛠️ Tecnologías Utilizadas

- **Backend:** Node.js, Express
- **Frontend:** HTML5, CSS3, JavaScript (DOM API)

## 📁 Estructura del Proyecto

```text
├── CSS/            # Hojas de estilo
├── imagenes/       # Imágenes de las armaduras
├── js/             # Scripts del cliente (DOM / Fetch)
├── public/         # Archivos HTML
├── server.js       # Servidor principal con Express
└── package.json    # Configuración de dependencias
